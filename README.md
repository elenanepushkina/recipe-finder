# recipe-finder
Веб-приложение для подбора рецептов по имеющимся продуктам на чистом JavaScript

## Основной функционал
* **Выбор продуктов:** интерактивный список базовых ингредиентов с возможностью множественного выбора и быстрого сброса.
* **Умный подбор:** отображение блюд, содержащих выбранные продукты, с подсветкой имеющихся и недостающих ингредиентов.
* **Фильтрация:** сортировка по приему пищи (завтрак, обед, ужин) и времени приготовления (быстрые блюда до 20 минут).
* **Карточка рецепта:** модальное окно с полным списком ингредиентов и пошаговой инструкцией.
* **Избранное:** сохранение понравившихся блюд в `localStorage` браузера.

## Технологии
* **HTML5** — семантическая разметка.
* **CSS3** — Flexbox, Grid, адаптивная верстка.
* **JavaScript (ES6+)** — нативный DOM API (`createElement`, `dataset`, `classList`, делегирование событий), ES-модули (`import`/`export`), `localStorage`.
